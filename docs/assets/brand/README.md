# Apptrol brand assets

Logo files for Apptrol: the mark, the wordmark, the full logo in light and dark versions,
one-colour variants, and PNGs from 16 to 512 px.

**How to use them — which file for which background, colours, clear space, minimum sizes,
construction and what not to do — is in the [brand guide](../../brand.md).**

| Folder | Contents |
|---|---|
| `./` | SVG master files (logo, mark, wordmark, variants) |
| [`png/`](png/) | Raster mark in 8 sizes, and the GitHub social preview |
| [`guide/`](guide/) | Drawings and colour swatches used by the brand guide |

The reasoning behind the design is in [ADR 0014](../../adr/0014-logo-and-visual-identity.md).
The files are covered by the project's [MIT license](../../../LICENSE).
