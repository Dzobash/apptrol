# 0009. MIT license

- **Status:** Accepted
- **Date:** 2026-09-28

## Context

The project is published openly. The GoXLR utility for Linux, which follows a similar idea,
uses the MIT license, as do the Go libraries Apptrol depends on.

## Decision

Apptrol is released under the MIT license.

## Consequences

- Anyone may use, modify and redistribute the code, including in closed products, as long
  as the copyright notice is kept.
- No license compatibility issues with the chosen dependencies.
