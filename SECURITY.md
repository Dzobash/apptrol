# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately via
[GitHub's private vulnerability reporting](https://github.com/Dzobash/apptrol/security/advisories/new).

You will get an answer within a week. Apptrol is a hobby project, so fixes are made on a
best-effort basis.
